# Changelog

## [1.1.0] - 07.11.2026

### Added

- New period "Last 4 weeks" (`4weeks`), which shows the 28 days up to today instead of the calendar month

### Changed

- Errors of providers in the log now name the affected source with a link to it
- Translate settings texts
- Updated settings lib

## [1.0.2] - 24.10.2026

### Changed

- Set compatibility with WordPress 7.2
- Updated dependencies

## [1.0.1] - 12.10.2026

The plugin has been renamed. An existing installation of version 1.0.0 will
not be updated as a result, because the plugin directory has changed.

### Changed

- Renamed the plugin to "threadi Now Pages" with the slug `threadi-now-pages`
- Renamed all hooks, options, transients, post types and the taxonomy accordingly

## [1.0.0] - 08.10.2026

### Added

- Initial release
